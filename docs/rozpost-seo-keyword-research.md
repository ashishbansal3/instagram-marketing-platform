## Method & confidence

| Item | Detail |
| --- | --- |
| **Paid tools** | Ahrefs / Semrush / Moz / Keyword Planner **not available** in this environment (no API keys; tool domains egress-blocked). |
| **Public signals used** | Category SERP composition (Buffer, Later, Predis.ai, Ocoya, local agencies); known head-term magnitudes from industry SEO literature; autocomplete / related-search patterns from prior India SMB marketing research in companions; directory/backlink playbooks for new SaaS. |
| **Volume figures** | **Public estimates** — monthly Google searches, India (`geo=IN`) unless noted. Ranges, not point claims. |
| **Competition** | Qualitative SERP difficulty: **Low / Medium / High** = new-domain rankability in ~6–12 months with good pages + some links. |
| **Confidence labels** | **High** = well-documented category head terms; **Medium** = calibrated from peers + intent; **Low** = long-tail / awkward phrasing / Indic script (thin tool coverage); **Speculative** = almost no evidence of real search demand. |
| **Re-verify** | Before spending on content at scale: pull Keyword Planner (Ads account) or Ahrefs/Semrush India DB and replace ranges. Track GSC impressions after index. |

**Important product SEO posture:** Exact assignment seeds like “automatic Instagram handler” are **buyer-phrasing experiments**, not proven head terms. Map them to **real search language** (auto post, schedule, marketing service, WhatsApp Instagram) while retaining exact-match coverage in FAQ / H2 / glossary where natural.

**How to read ranges:** Midpoint is planning default; treat as **order-of-magnitude**. Confidence **Medium** unless labeled otherwise. Replace with Planner export before any paid SEO spend.

**SERP competition pattern (EN India):**

- **Tool head terms** (`Instagram scheduler`, `auto post`): Buffer, Later, Meta Business Suite, Predis, Hootsuite-class — **High**.
- **Service terms** (`Instagram marketing agency/service`): local agencies + marketplaces — **High** authority needed; win with niche + WhatsApp angle.
- **Wedge terms** (`WhatsApp to Instagram`, vertical salon/clinic): thin / weak pages — **Low–Medium** — best early wins.
- **Handler phrasings**: almost empty intentional SERPs — treat as **supporting**, not pillars.

## 3) On-page SEO plan (route-level)

### Shared rules

- **One primary keyword + 2–4 secondaries** per indexable URL.
- **Title:** ≤ ~60 chars; brand at end: `{Primary} | RozPost`.
- **Meta description:** 140–160 chars; include CTA (Start free / Send WhatsApp photo).
- **H1:** one per page; match primary intent, not stuffed.
- **Density:** primary phrase ~0.8–1.5% of body copy; prefer natural synonyms. Never force “handler” into H1 if awkward — use FAQ.
- **Internal links:** every page links to `/onboarding` CTA; blog posts link to `/`, `/onboarding`, `/connect` with descriptive anchors.
- **`/dashboard`:** `noindex,nofollow` (auth app).
- **Canonical + OG/Twitter** on all public pages; JSON-LD `SoftwareApplication` on `/`, `HowTo` on `/connect`, `FAQPage` where FAQs exist, `BlogPosting` on posts, `LocalBusiness` operator entity (Punjab) on `/` footer or `/about` when added.
- **`lang="en"`** root; mark Indic snippets with `lang="hi"` / `lang="pa"` where present.

## 4) Technical SEO

### 4.1 Core Web Vitals (targets)

| Metric | Good | RozPost plan (Next.js 15 App Router on Vercel) |
| --- | --- | --- |
| **LCP** | < 2.5s | Hero text or optimized LCP image via `next/image` + `priority`; avoid lazy on hero; edge static for `/`, `/blog` |
| **INP** | < 200ms | Minimal client JS on marketing pages; defer analytics; keep onboarding forms lean |
| **CLS** | < 0.1 | `next/font` with `display: "swap"` + size-adjusted fallbacks; width/height on images; no late-inject banners |
| **TTFB** | < 800ms | Static/ISR marketing routes; region close to India (Vercel BOM/SIN if available) |

Ship: `robots.txt`, `sitemap.xml` (exclude `/dashboard`), canonicals, HTTPS, compressed images (AVIF/WebP), no render-blocking third parties on first paint.

### 4.2 Images

- Marketing: `next/image`, explicit sizes, blur placeholder optional.  
- **Above fold:** `priority` / `fetchPriority="high"`.  
- **Below fold:** default lazy.  
- Alt text: descriptive + light keyword (“Salon product photo ready for Instagram via RozPost”) — not spam.  
- Blog: max dimension sensible (≤1600w); captions where helpful.

### 4.3 Devanagari / Gurmukhi font optimization

Product creatives already plan **Noto Sans Devanagari / Gurmukhi** in Remotion. For the **website**:

```ts
// apps/web — load only needed subsets; do not preload every Indic face on every page
import { Noto_Sans_Devanagari, Noto_Sans_Gurmukhi } from "next/font/google";

const notoDeva = Noto_Sans_Devanagari({
  subsets: ["devanagari"],
  weight: ["400", "600"],
  display: "swap",
  variable: "--font-deva",
  preload: false, // enable true only on routes that show HI body copy
});

const notoGuru = Noto_Sans_Gurmukhi({
  subsets: ["gurmukhi"],
  weight: ["400", "600"],
  display: "swap",
  variable: "--font-guru",
  preload: false,
});
```

| Rule | Why |
| --- | --- |
| Subset by script | Full Noto files are large; hurt LCP |
| `preload: false` by default | Most pages are EN-only; avoid unused font bytes |
| Apply `lang` + CSS variable only on Indic nodes | Prevents Latin text from pulling Indic fonts |
| Self-host via `next/font` | No layout shift from Google CSS; better CLS |
| Remotion vs Web | Keep creative fonts in worker pipeline; web fonts ≠ reel fonts necessarily, but same family OK |
| Fallback stack | `"Noto Sans Devanagari", "Noto Sans", system-ui` / Gurmukhi equivalent |

### 4.4 Indexing & structure

- App Router metadata API per route (`title`, `description`, `openGraph`, `alternates.canonical`).  
- JSON-LD as above.  
- No soft-404 empty blogs.  
- Pagination only when blog > ~20 posts.  
- Prefer static generation for blog; revalidate on publish.

### Phase C — Editorial & experts (ongoing)
- Connectively / Qwoted / Featured: comment on SMB + Instagram + WhatsApp topics

### Phase D — Product-led links
- Free public tools: “Instagram Professional checklist”, “Caption language checker (HI/PA)” — earn natural links

- Skip PBNs, Fiverr link packs, guest-post farms  
- Track in a simple sheet: URL, date, type, live?, notes

## SEO decisions (summary for implementers)

1. **Own the WhatsApp→Instagram wedge** before fighting “Instagram scheduler.”  
2. **Vertical pages/posts** (salon, clinic, shop) over generic agency keywords early.  
3. **Exact “handler” seeds** → FAQ only.  
4. **`/dashboard` noindex.**  
5. **EN-first site**; Indic as snippets/captions with subset fonts, not full bilingual IA at MVP.  
6. **Punjab GBP** for trust/local; national growth via content + directories.  
7. **Re-measure volumes** with Keyword Planner/Ahrefs before scaling blog beyond the 8 outlines.
